# 🤖 Nexus AI - Assistente Pessoal Web

Um assistente pessoal moderno, responsivo e interativo construído em **HTML5, CSS3 e JavaScript Vanilla**.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-ativo-emerald.svg)

## 🌟 Funcionalidades
- 💬 **Interface de Chat**: Balões de mensagens modernos e organizados.
- 🎙️ **Comando de Voz**: Suporte à Web Speech API para ouvir comandos por microfone.
- 🔊 **Síntese de Voz (TTS)**: O assistente responde falando com você.
- 🧮 **Comandos Inteligentes**: Data, hora, cálculos, buscas no Google e YouTube, piadas.
- 📱 **Totalmente Responsivo**: Funciona em computadores, tablets e smartphones.

## 🚀 Como Executar Localmente
1. Baixe os arquivos do repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
